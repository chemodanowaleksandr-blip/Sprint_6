# Финальный проект 6-го спринта: Автотесты для сервиса «Яндекс.Самокат»

Учебный проект по автоматизации UI-тестирования веб-приложения «Яндекс.Самокат» с использованием паттерна Page Object Model (POM).

## Использованные технологии и инструменты
* **Python 3.10** — язык разработки автотестов.
* **Selenium WebDriver** — инструмент для автоматизации действий в браузере.
* **pytest** — фреймворк для написания, структурирования и запуска тестов.
* **Allure Report** — инструмент для генерации красивых и понятных отчетов о прохождении тестов.
* **GitHub Actions** — CI/CD инструмент для автоматического запуска тестов в облаке при каждом пуше.

## Структура проекта
* `locators/` — локаторы элементов страниц, разделенные по функциональности.
* `pages/` — классы Page Object с логикой работы страниц и базовым классом `BasePage`.
* `tests/` — параметризованные UI-тесты (тестирование заказа самоката и выпадающих списков).
* `conftest.py` — фикстура для инициализации и конфигурации веб-драйвера Firefox (в режиме headless).
* `.github/workflows/allure.yml` — конфигурация автоматического запуска тестов на сервере GitHub.

## Как запускаются тесты в репозитории
Тесты запускаются автоматически при любом изменении в ветке `scooter-tests` благодаря настроенному роботу в GitHub Actions. Результаты прогона и отчеты Allure сохраняются в артефактах сборки.
